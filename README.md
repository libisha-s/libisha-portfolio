# Libisha S Portfolio

A simple responsive React + Vite portfolio using the requested palette:

- #E6F2DD
- #B1D3B9
- #88BDA4
- #659287

## Run locally

1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite.

## Customize

- Main content: `src/main.jsx`
- Colors and layout: `src/styles.css`
- Page title/description: `index.html`
